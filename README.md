# Retail Sales Dashboard & AI Analytics Engine
**AICTE | IBM SkillsBuild Data Analytics Internship (BharatCares) Final Project**

## Project Overview
This project constructs an end-to-end data analytics and predictive modeling pipeline styled around an executive 5-Level Retail Dashboard. It evaluates financial performance, isolates structural risks using machine learning, and outlines data-driven strategies.

## Dataset Source
* Standard Retail Superstore / Online Transactional Data Schema.
* Attributes: Order_ID, Order_Date, Customer_ID, Category, Sub_Category, Sales, Quantity, Discount, and Profit.

## Tech Stack & Libraries
* **Python** (Core Language)
* **Pandas & NumPy** (Data Preprocessing & Manipulation)
* **Scikit-Learn** (Random Forest Regressor & Machine Learning Drivers)
* **Matplotlib & Seaborn** (Data Visualization & Theme Styling)
